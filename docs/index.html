px2svg

Pixel art a SVG: los píxeles del mismo color se unen en un solo <path>. Se ejecuta entero en tu navegador, la imagen no sale de tu equipo.

Código en GitHub

Arrastra una imagen, pega con Ctrl+V o haz clic

PNG, JPEG, GIF, WebP, AVIF… lo que decodifique el navegador

Detecta la rejilla midiendo la periodicidad del gradiente, reduce la imagen a sus píxeles reales y traza el contorno de cada región con fill-rule="evenodd".
